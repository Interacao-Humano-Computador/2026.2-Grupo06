# Padrões do projeto

Todo artefato publicado neste site reutiliza o mesmo contrato. Isso evita nota cortada em histórico de versão, autoria, legendas e referências.

## O que reutilizar

| Padrão | Para que serve | Página |
| --- | --- | --- |
| Template completo | Copiar e preencher um artefato novo | [Template de artefato](template-artefato.md) |
| Autoria e versões | Histórico, autor, revisor e contribuição | [Autoria, revisão e versões](autoria-revisao-versoes.md) |
| Figuras, tabelas e ABNT | Legenda, fonte, chamada no texto e referências | [Figuras, tabelas e referências](figuras-tabelas-referencias.md) |
| Acessibilidade | Contraste, texto e imagens | [Acessibilidade](acessibilidade.md) |
| Fluxo de publicação | Branch, commit e o que não esquecer | [Como contribuir](como-contribuir.md) |

## Ordem mínima de um artefato

1. Tabela de contribuição com hiperligações
2. Introdução
3. Conteúdo, com figuras e tabelas nomeadas
4. Histórico de versão
5. Referências
